## User Need
User need to be able to use comments

## High-Level Requirements
- Comments should have it's own UI module
- Comments should have it's own feature (domain and data) modules
- Comments SHOULD NOT use local/cache data source, only REMOTE
- All comments should be mocked in the data source
- All existing mocks from comments should be removed and replaced by the ones you just created
- Get comments should receive an id to know where to fetch the comment from
- Comments are paginated

## Business Value
User should be able to see comments from Movie reviews, Movies Lists and any other screen that have comments

## Priority
High - This is a MUST feature
