## User Need
Block screens with auth screen

## High-Level Requirements
- Block Profile, Social and New Activity tabs with Login screen
- If the user clicks in any of these tabs, open the login screen
- Login screen MUST be a modal
- If the user tries to make any write action (like a review, like a movie, add a comment, etc) block the action and show the login flow


## Business Value
Login flow should block some of the actions/screens

## Priority
High - This is a MUST feature
