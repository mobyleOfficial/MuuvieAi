## User Need
User need to be able to see a Movie review screen with more data

## High-Level Requirements
- Be able to like the review
- Be able to navigate to the movie the review is about
- See the user who created the review and navigate to it
- See how many likes the review has
- See the comments from the review
- See reviews from this movie from other users
- See more movie revies from this user
- Be able to share the review (whatsapp, instagram, email, etc)

## Business Value
Enables user to interact with the movie review screen

## Priority
High - This is a MUST feature
